# Pet Companion · 宠物随行

在《最终幻想 XIV》国服，把「63页」或「蝴蝶效应」换成喜欢的人物，让它跟着你走。换装、染色和动作只在你自己的游戏画面里显示。

## 卫月订阅

已订阅[国服插件总库](https://github.com/Alittlerecallinglittlebrother/DalamudCN-Plugins)的玩家，在插件安装器里搜索 **Pet Companion** 即可。也可以单独订阅本插件。

## 在游戏中使用

在聊天框输入 **/petcompanion** 或 **/page63** 打开窗口。第一次用可以在「角色 → NPC 外观」里选塔塔露，点「应用到随行宠物」，召出「63页」或「蝴蝶效应」，再打开「启用随行」。

- **角色**　可以保存附近已加载的玩家和人形 NPC，也可以导入、导出 Brio 或 Anamnesis 的 .chara 文件。在「已保存」选中文件，点「删除文件」，核对文件名后确认即可移出角色库。
- **选中和改名**　人物出现后，可以直接点它，也可以在「角色 → 当前随行外观」点「选中人物」。点「改名」可以给这套外观取名字，留空并保存就会恢复原名。
- **衣装**　先选部位，再按名称或道具编号换装备。支持染色的装备可以分别调整各个染色通道。
- **待机动作**　等宠物站稳后手动播放，或设为站定一段时间后自动播放。
